コマンド対訳

      
Cisco・Juniper・Huawei・ヤマハ・アライドの主要コマンドを横並びで比較。どのベンダーのコマンドでも、操作名（ARP、保存、OSPF…）でも検索できます。

      

        
        
        

        

        
機種や OS バージョンで書式が異なる場合があります。「—」は該当コマンドなし／未収録。

オフライン・設定

      
すべての計算と検索は端末内で完結し、外部との通信は行いません。

      
オフライン利用

        

        

        
PC で使う
          
    
            
  1. 「オフライン版HTML」を保存する（zip内の index.html でも同じ）。
    2. 
            
  2. ファイルをダブルクリックしてブラウザ（Chrome / Edge / Firefox / Safari）で開く。インターネット接続なしで全機能が動きます。
    3. 
            
  3. USBメモリや共有フォルダに置いておけば、どの端末でも使えます。
    4. 
          

        
スマホ（iPhone / Android）で使う
          
    
            
  1. zip（PWAパッケージ）の中身を、社内Webサーバ・NAS・GitHub Pages など HTTPS で見られる場所に置く。
    2. 
            
  2. スマホでそのURLを一度開く（この時点でオフライン用にキャッシュされます）。
    3. 
            
  3. iPhone：Safari の共有ボタン →「ホーム画面に追加」
    Android：Chrome のメニュー →「アプリをインストール」（または「ホーム画面に追加」）
    4. 
            
  4. 以後はホーム画面のアイコンから、機内モードや圏外でも起動できます。
    5. 
          

          
スマホのブラウザはHTMLファイルを直接開いても動かないことが多いため、この手順をおすすめします。
